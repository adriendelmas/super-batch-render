## RenderCue
- **What:** Super Batch Render is derived from RenderCue. Reused ideas and structure: the job queue stored on the
  WindowManager and persisted in a hidden Text block, the background Blender process driven by a JSON
  manifest, the JSON status file polled by the UI, and the pause signal file.
- **Author:** Usama Bin Shahid
